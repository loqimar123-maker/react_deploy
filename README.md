# Plug in to Power On

Konsep formulir login React dengan suasana meja kerja: sambungkan steker untuk menyalakan monitor.

## Menjalankan project

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan oleh Vite.

## Interaksi

- Klik steker atau seret ke stopkontak untuk menyalakan monitor.
- Isi formulir dan pilih ikon mata untuk melihat kata sandi.
- Password yang salah memutus sambungan dan memadamkan monitor.
- Klik steker untuk menyambungkan kembali dan mencoba lagi.
